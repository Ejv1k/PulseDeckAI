Phase 4B talkover remains unimplemented. The existing Master path has per-deck `masterEQNode` and `masterFaderNode`, while Cue uses separate nodes/engine. Do not use `DeckAudioGraph.eqParameters` for talkover: it updates both Master and Cue EQ. The Master fader is recomputed from channel volume × crossfader weight, so talkover must compose as isolated attenuation state and preserve both user values. Existing 3-band EQ (low shelf ~250 Hz, mid peak ~1.2 kHz/Q 1, high shelf ~3.5 kHz) does not exactly model −4 dB across 300 Hz–3 kHz; a Master-only EQ path or an explicitly accepted approximation is needed. Proposed acceptance covers T-key idempotence, 800 ms linear ramp to 0.15 and 800 ms restore, EQ restoration, Cue/preview isolation, cancellation, overlap, and teardown, using mocked output/offline rendering only. This is a bounded draft map only; no Phase 4B implementation is authorized.

Phase 1C uses separate master and cue meters. Each accepts Float32 mono/stereo output at 8–192 kHz, reports RMS, peak, and 512 linear FFT bins from a 1024-point transform, and carries the callback sample rate and host time. A 32-record bounded ring drops newest records on overflow. Its fixed storage, vDSP setup, and workspaces are prepared before tap installation; unsupported lock-free atomics fail startup. Tap code does not allocate, lock, perform I/O, message actors, access an input node, or start playback.
