Phase 4B talkover is implemented. The deck Master signal path uses dedicated `masterTalkoverEQNode` and independent multiplier composition in `masterFaderNode`, while Cue uses separate nodes/engine. `DeckAudioGraph.eqParameters` is preserved untouched for user and transition EQ. The Master fader is recomputed from channel volume × crossfader weight × talkover multiplier, preserving user and automation values across toggles. A dedicated Master-only parametric EQ band (center ~948.7 Hz, bandwidth 3.32 octaves) models the −4 dB vocal pocket dip without approximating through the existing 3-band user EQ. Acceptance proves T-key and button toggle, 800 ms linear ramp to 0.15 and 800 ms restore, midpoint/endpoints, mid-ramp reversal continuity, cancel/reset, idempotence, Cue/preview isolation, track change overlap, and engine lifecycle teardown using mocked output and offline rendering only.

Phase 1C uses separate master and cue meters. Each accepts Float32 mono/stereo output at 8–192 kHz, reports RMS, peak, and 512 linear FFT bins from a 1024-point transform, and carries the callback sample rate and host time. A 32-record bounded ring drops newest records on overflow. Its fixed storage, vDSP setup, and workspaces are prepared before tap installation; unsupported lock-free atomics fail startup. Tap code does not allocate, lock, perform I/O, message actors, access an input node, or start playback.
